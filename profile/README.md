# Synfig Studio - Keyframes You Set

Synfig Studio is a vector animation tool for motion you design. Parameters change between keyframes. The canvas starts from your objects, not from a supplied cartoon.

---

## Product Snapshot

Draw or import a shape you made, set two keyframes, and play the interpolation. If the motion is wrong, move a keyframe. Do not edit the rendered video to fix the pose. Render after the project plays inside Synfig and you have saved.

Layers keep a background apart from the character you are moving. Bones, if you use them, belong to a rig you understand. Skip them until a simple shape already renders. A missing image is a path. Put your file back. Synfig will not supply a character you did not draw.

## Live Production

Use it for a logo sting you designed or a short instructional move you are allowed to publish. Keep the project and the render in one folder you back up. Watch the movie in a normal player. If the last frame is wrong, change the keyframe and render again.

A long scene with empty keyframes is harder to debug than two seconds that already loop. Synfig does not clear rights to footage you import. Import only what you may use.

---

## Render the Short Span

A two-second move that plays outside Synfig is the proof. Add another layer only after that file looks right. Bones and long scenes wait until the simple shape already renders.

---

## Setup Path

Prerequisites: A folder for the project, and one motion you can describe.

1. Install Synfig Studio and save a new project in that folder.
2. Add one shape you drew and two keyframes.
3. Play the span inside Synfig.
4. Save, then render a short file with a new name.
5. Watch it outside Synfig. Keep the project.

## Who Benefits

Synfig Studio fits a short vector move you author. It does not fit tracing someone else's film, a render-only folder with no project, or a first session spent on a rig you cannot explain.

---

## Fixes

Nothing moves: the keyframes are on the same values, or you are playing the wrong time. The render is empty: the path was wrong or the project was not saved. An image is missing: restore the file next to the project. You imported a clip you do not own: remove it before you render.
